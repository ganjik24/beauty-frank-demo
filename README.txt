BEAUTY FRANK — демонстрационная версия сайта

Как открыть на компьютере:
1. Откройте файл index.html двойным щелчком.
2. Сайт работает без сервера, установки и сборки.

Как загрузить на хостинг:
1. Загружайте всё содержимое папки client-demo, сохраняя структуру папок.
2. Файл index.html должен находиться в корне сайта.
3. Никакие фреймворки, npm-команды или серверные настройки не требуются.

Важно:
- не переименовывайте папки assets, public, services, team и остальные разделы;
- форма на демонстрационном сайте не отправляет данные на сервер;
- папка содержит только файлы, необходимые для показа сайта.
